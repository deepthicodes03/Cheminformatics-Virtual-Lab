# Cheminformatics Virtual Laboratory

## About the Project
The Cheminformatics Virtual Laboratory is an interactive Python-based application designed to help students learn cheminformatics and molecular visualization.

## Features
- SMILES notation reading animation
- 2D molecular structure visualization
- 3D molecular visualization
- Molecular graph representation (atoms as nodes and bonds as edges)
- Adjacency matrix generation and CSV export
- Molecular property calculations
- Structure–property analysis
- PDF molecular properties reports
- Interactive assessments and final project

## Technologies Used
- Python
- Streamlit
- RDKit
- Pandas
- Matplotlib
- py3Dmol
- ReportLab

## How to Run

1. Clone this repository:
   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Install the required libraries:
   ```bash
   pip install -r requirements.txt
   ```

3. Run the application:
   ```bash
   streamlit run cheminformatics_virtual_lab_updated.py
   ```

## Project Purpose
This project provides an interactive learning environment for understanding molecular structures, SMILES notation, molecular properties, and graph-based molecular representations.
